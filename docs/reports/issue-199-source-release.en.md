## API, CLI and schema consumption

The static declaration comparison found no removals, 21 additions and nine changed declarations. Changes include eight added fields across seven experimental structs and r1→r2 changes to SvcFormat/SvcCompositeSchema. Added fields can affect source compatibility for unkeyed struct literals. No existing field type or JSON tag was removed/changed in those seven structs. This is not a complete behavioral or wire-compatibility guarantee.

DeriveDynamicSQLChecked returns a typed error for invalid capture ranges. For such input, the existing DeriveDynamicSQL returns a zero value with empty Mapping rather than a valid empty fact result. ValidateTree rejects a root field and an empty field. SVC r2 and legacy r1 consumption boundaries must be pinned explicitly.
